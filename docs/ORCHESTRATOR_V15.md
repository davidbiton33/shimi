# AgentOS v1.5 — Zero-Friction Orchestrator (עברית)

המשתמש לא צריך לזכור פקודות תחזוקה במהלך פיתוח רגיל. סוכן שמזהה `agentos.yml` משתמש ב־Skill או ב־MCP `agentos_work` כדי לפתוח/לחדש Session, לספק Context לפי צורך ולתעד החלטות.

**חריג מכוון: מעבר בין סוכנים הוא יזום על ידי המשתמש בלבד.**

## שימוש פעם אחת בפרויקט

```powershell
agentos setup --dry-run
agentos setup
```

מאתחל פרויקט Git אם צריך, מתקין Rules ו־Skills ותצורות MCP ל־Claude, Cursor, Codex באופן מקומי בלבד. ניתן להגביל לסוכן מסוים: `--client codex`, `--client claude`, `--client cursor`. התנגשויות בהגדרות קיימות גורמות לכישלון ללא דריסה. יש לטעון מחדש את הסוכן ולאשר חיבור MCP כשנדרש.

## עבודה רגילה — אין צורך בפקודות ידניות

הסוכן מפעיל `agentos work --json` או MCP `agentos_work` פעם אחת בכניסה לסשן. לאחר מכן הוא משתמש ב־Context, בזיכרון וב־Session Notes בהתאם לצורך. אם המנוע מזהה Session פעיל, הוא משתמש בו ולא יוצר חדש. Watcher פועל לפי הגדרות `agentos.yml`; המנוע לא מריץ בדיקות, לא מפעיל מודל AI ולא מפעיל מעבר לסוכן אחר.

## מעבר בין סוכנים — שתי פקודות מכוונות

**בטרמינל של הפרויקט אחרי שנגמרים הטוקנים / המשתמש מחליט לעבור:**

```powershell
agentos switch
```

הפקודה עוצרת Session פעיל בצורה מסודרת, מסנכרנת מצב Git, יוצרת Checkpoint, מעדכנת Pack ומייצאת Handoff. היא עובדת גם אם הצ'אט של הסוכן כבר לא זמין; במקרה זה אין דרך לשחזר החלטות שהסוכן מעולם לא תיעד.

**אחרי פתיחת סוכן חדש, באותו Git Worktree ובאותה תיקיית `.ai`:**

```powershell
agentos continue
```

הפקודה קוראת את ה־Handoff, את מצב Git ואת רעננות הראיות הישנות **לפני** פתיחת Session חדש, ומחזירה מידע לסוכן החדש על המשימות שנותרו. היא לא מחליפה סוכן באופן אוטומטי. אם ה־Session הישן עדיין פעיל, היא תסרב עד להרצת `agentos switch` ידנית.

## מגבלות חשובות

- MCP ו־Skill אינם משכפלים היסטוריית שיחות; אין גישה לתמליל הפרטי של הסוכן הקודם.
- ההעברה מתבססת על אותו עותק Git ועל אותם קובצי `.ai`; Checkpoints אינם גיבוי לקוד שלא בוצע לו Commit.
- `work`, `switch` ו־`continue` לא מריצים בדיקות פרויקט. יש לקבל אישור לבדיקות מפורשות כאשר הקוד אינו מהימן.
- ניטור אוטומטי נשען על Git/Watcher ועל אירועים שהסוכן תיעד במפורש. לא ניתן להבטיח שסוכן בכל IDE יטען את ה־Skill או יפעיל MCP ללא אישור משתמש.
- `agentos start`, `checkpoint`, `end`, `pack`, `resume`, `guard`, `evidence` וכל שאר הפקודות נשארות זמינות למשתמשים מתקדמים ולדיבוג.
