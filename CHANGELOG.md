# Changelog

## 1.6.0-beta.1 — SHIMI public branding candidate

- Renamed public CLI command to `shimi` with `agentos` compatibility alias.
- New package metadata `shimi-agent-cli` (not yet registered on npm).
- Introduced SHIMI Skill paths, MCP connection name, server name and resources.
- Legacy MCP generated entries migrate when recognizable; unknown custom entries are preserved or blocked safely.
- Existing `.ai`, `agentos.yml` and old tool IDs remain supported.
- Added public-facing README, contribution/security policy, issue templates and migration guide.
- No semantic/behavioral changes to the evidence engine; first public beta remains subject to release gates.
